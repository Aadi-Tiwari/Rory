# Dataset source ledger

Research date: 2026-10-20. This ledger records public documentation actually inspected. No restricted patient records were downloaded, no agreement was accepted, and no request was submitted.

| Source | Version/date and inspection | Supported point and limit |
| --- | --- | --- |
| [Paediatric Intensive Care database](https://physionet.org/content/picdb/1.1.0/) | Version 1.1.0, published 2020-11-12. Read description, methods, de-identification, access rules and release notes through indexed full text and direct HTML. | Single-center Chinese critical-care data; original notes withheld; patient-specific date shifts. Excerpt: "We could not release the original clinical documents at this stage." Documentation host was unavailable. |
| [PIC CHARTEVENTS documentation](https://github.com/Healthink/PIC/blob/master/pic-doc/src/components/Pages/chartevents.vue) | Author repository, retrieved raw source. | Measurement and storage times differ. Excerpt: "STORETIME records the time at which an observation was manually input or manually validated". Live branch, not a verified release-specific dictionary. |
| [PIC EMR_SYMPTOMS documentation](https://github.com/Healthink/PIC/blob/master/pic-doc/src/components/Pages/emr_symptoms.vue) | Author repository, retrieved raw source. | Extracted symptoms include discharge-summary content; RECORDTIME represents recording on the clinical system. |
| [PIC diagnoses documentation](https://github.com/Healthink/PIC/blob/master/pic-doc/src/components/Pages/diagnoses_icd.vue) | Author repository, retrieved raw source. | Excerpt: "The ICD codes are generated for billing purposes at the end of the hospital stay." |
| [PIC admissions documentation](https://github.com/Healthink/PIC/blob/master/pic-doc/src/components/Pages/admissions.vue) and [patients documentation](https://github.com/Healthink/PIC/blob/master/pic-doc/src/components/Pages/patients.vue) | Author repository, retrieved raw source. | Patient identifiers, demographics, mortality fields, ED timing and preliminary admission diagnosis. Counts in old docs are inconsistent, so they were not used. |
| [PECARN datasets](https://pecarn.org/datasets/) | Current Registry 2012-2021 listing and access terms inspected. | Real pediatric ED registry; access requires recipient agreement and contact information. General policy requires institutional IRB approval or exemption. No form action taken. |
| [PECARN Registry v1 public-use data dictionary](https://pecarn.org/wp-content/uploads/2026/02/PECARN-Registry-v1-PUD-Dataset-Specifications.xlsx) | Retrieved to memory with Python urllib; parsed every worksheet with openpyxl. | Exact released field coverage and absent modalities. This is a schema audit, not proof of nonmissing measurements in patient records. Browser retrieval failed because XLSX was unsupported; direct retrieval succeeded. |
| [PECARN Registry protocol](https://pecarn.org/studyDatasets/documents/Registry%20Protocol%2012.20.12.pdf) | Version 1.02, 2012-12-20. Read data-domain and extraction sections. | The parent registry considered narrative text. The public-use dictionary, rather than this older protocol, determines what outsiders receive. |
| [External validation of a paediatric Smart triage model for use in resource limited facilities](https://journals.plos.org/digitalhealth/article?id=10.1371/journal.pdig.0000293) | Published 2024-06-21. Read methods, primary outcome, predictors, eligibility, and access statement. | Pediatric outpatient triage with independent Kenyan sites, but data sharing is restricted and the outcome is not a sepsis-onset label. |
| [Geographical validation of the Smart Triage Model by age group](https://borealisdata.ca/dataset.xhtml?persistentId=doi:10.5683/SP3/4OI0BI) | Public Dataverse metadata API inspected, version 2. | Listed clinical CSVs and code files are marked restricted. CC BY-NC-SA metadata does not remove file-access restrictions. |
| [Pediatric Sepsis Data Challenge](https://sepsis.ubc.ca/research/current-research-projects/pediatric-sepsis-data-challenge) | Current organizer page, read dataset and evaluation descriptions. | Participant training data are synthetic; original test records are withheld. Excerpt: "unseen and unavailable to participants". Challenge has ended. |
| [Continuous Renal Replacement Therapy Attenuates Endothelial Injury Biomarkers in Pediatric Sepsis: A Prospective Cohort Study](https://doi.org/10.6084/m9.figshare.30812312.v1) | Figshare API metadata: 2025-12-06, version 1, CC0. Retrieved Original data.xlsx to memory and inspected workbook headers. | An actual freely downloadable real-data release, but it lacks Rory's measurement and text inputs. File was not written to the repository. SHA-256: `0fa15668c8c0599919c7a96945178ee540a36e69be20c9275d4aba031e494e48`. |
| [Prognostic Evaluation of SOFA and PSS Scores in Pediatric Patients with Septic Shock Admitted to the PICU: A Comparative Analysis](https://doi.org/10.5281/zenodo.15081539) | Zenodo API metadata: 2025-03-25, open, CC BY 4.0. Related [study paper](https://advances.umw.edu.pl/ahead-of-print/204830.pdf) abstract inspected. | Another real public shock cohort. Only metadata and study description inspected; the XLS schema was not verified. The latest repository version contains a supplementary document, so it must not be mistaken for the original raw-data release. |

Discovery used public searches for PIC, pediatric ED sepsis datasets, PECARN, Smart Triage, and Figshare/Zenodo releases. Public metadata APIs and bounded in-memory workbook inspection resolved browser retrieval failures. Search snippets without primary-source retrieval were not used to establish dataset fit. No patient-level values were retained in these notes.
